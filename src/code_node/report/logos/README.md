# Logos

The logos code-node's graph draws, from [gilbarbara/logos](https://github.com/gilbarbara/logos) through Iconify's `@iconify-json/logos` 1.2.17, under CC0-1.0. Each is its company's trademark, shown to name the service the code reaches.

Written by `scripts/logos.py` (`make logos`): don't edit them. Each one's ids carry its name, and near-black fills are `currentColor`, so they show in dark mode.
