# Logos

The logos code-node's graph draws, in two sizes, as favicons come. Each is its company's trademark, shown to name the service the code reaches.

- `<name>.svg`: the full art, from [gilbarbara/logos](https://github.com/gilbarbara/logos) through Iconify's `@iconify-json/logos` 1.2.17 (CC0-1.0).
- `small/<name>.svg`: for an AWS service, a mark that reads at 16 to 32 px: its icon's own colour with code-node's white symbol for what it is, as AWS draws its 16 px icons.

Written by `scripts/logos.py` (`make logos`): don't edit them. Each one's ids carry its name, and near-black fills are `currentColor`.
